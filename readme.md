Untuk melihat tampilan website secara langsung di browser, ikuti langkah-langkah berikut:
1. Pastikan kamu sudah mengunduh seluruh folder proyek ini ke komputer kamu.
2. Buka folder proyek menggunakan Visual Studio Code (VS Code).
3. Pastikan kamu telah menginstal extension “Live Server” pada VS Code.
    - Jika belum, buka tab Extensions di VS Code (ikon berbentuk kotak di sidebar kiri).
    - Ketik “Live Server” pada kolom pencarian.
    - Klik Install untuk menambahkan extension tersebut.
4. Setelah terpasang, cari file bernama index.html di dalam folder proyek.
5. Klik kanan pada file index.html, kemudian pilih opsi “Open with Live Server.”
6. Secara otomatis, browser default kamu akan terbuka dan menampilkan halaman utama website ini.
